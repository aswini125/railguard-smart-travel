# 🚄 RailGuard — Smart Travel Intelligence

A modern, AI-powered Indian railway booking interface that helps travelers find the best train based on budget, crowd levels, weather, and urgency.

## 🌟 Features

- **🤖 AI-Powered Smart Search** — Recommends the best train based on your preferences (budget, speed, comfort, crowd)
- **🚨 Emergency & Priority Booking** — Fast-track booking for medical emergencies, senior citizens, and defense personnel
- **📊 Live Dashboard** — Real-time stats on train occupancy, bookings, and emergency quota usage
- **🌤️ Weather Strip** — Shows weather conditions at departure, en-route, and destination cities
- **🔀 Alternative Routes** — AI-suggested alternate routes with savings and crowd comparisons
- **📱 Fully Responsive** — Works seamlessly on mobile, tablet, and desktop

## 🚀 Getting Started

### Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/aswini125/railguard-smart-travel.git
   ```

2. Navigate into the folder:
   ```bash
   cd railguard-smart-travel
   ```

3. Open `index.html` in your browser — no build tools or dependencies needed!

## 💡 Key Highlights

- **No frameworks or libraries** — pure HTML, CSS, and JavaScript
- **CSS custom properties** for consistent theming across the entire UI
- **Shimmer loading states** for a polished user experience
- **Dynamic card rendering** with occupancy bars, AI notes, and badge tags
- **Modal booking flow** with PNR confirmation simulation
- **Dark mode UI** with noise overlay and grid background for a premium feel
